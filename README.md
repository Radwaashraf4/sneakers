# STRIDE — Sneakers Store

A responsive front-end e-commerce landing page for a sneakers store, built with plain
HTML, CSS, Bootstrap 5 and vanilla JavaScript. No frameworks, no backend — cart data
is saved in the browser's localStorage.

## Features
- Product catalog rendered dynamically from a JS array
- Live search by product name
- Category filters (Running, Basketball, Casual, Training)
- Shopping cart (Bootstrap offcanvas panel)
  - Add / remove items
  - Increase / decrease quantity
  - Auto-calculated total price
  - Cart persists after page refresh (localStorage)
- Responsive layout (mobile, tablet, desktop)
- Newsletter subscribe form (UI only)

## Tech Stack
- HTML5
- CSS3 (custom styling on top of Bootstrap)
- Bootstrap 5 (grid, navbar, offcanvas)
- Vanilla JavaScript (ES6)
- Bootstrap Icons
